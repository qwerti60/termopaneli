# Каталог: фильтр, сортировка и поиск

## Что реализовано

### Фильтр в каталоге

Файл приложения: `lib/screens/catalog_screen.dart`.

Кнопка `Фильтр` открывает нижнюю панель. Сейчас доступны:

- фильтр по материалу;
- фильтр по цвету;
- сброс фильтра;
- применение выбранных значений.

Фильтр работает локально по уже загруженному списку выбранной категории. Если выбрана категория `Откосы`, фильтр строится по откосам. Если выбрана категория `Все`, фильтр строится по всем загруженным позициям.

### Сортировка в каталоге

Файл приложения: `lib/screens/catalog_screen.dart`.

Кнопка `Сортировка` открывает нижнюю панель. Сейчас доступны:

- по названию А-Я;
- по названию Я-А;
- сначала дешевле;
- сначала дороже;
- по категории.

Сортировка работает локально, без дополнительного запроса к серверу.

### Поиск

Файл приложения: `lib/screens/search_screen.dart`.

Экран `Поиск` загружает каталог и ищет по тексту. Сейчас поиск проверяет:

- название;
- описание;
- категорию;
- артикул;
- код/модель;
- материал;
- цвет.

При нажатии на найденный результат открывается карточка товара.

## Что оставить на следующий этап

- Фильтр по цене от/до.
- Фильтр по толщине.
- Фильтр по ширине/размеру.
- Фильтр `только с фото`.
- Серверный поиск через API, если каталог станет большим.
- Серверная сортировка через API, если количество позиций будет большим.
- Поиск с подсказками и историей запросов.

## Проверки на телефоне

- Открыть каталог и переключить категории.
- Нажать `Фильтр`, выбрать материал, применить.
- Нажать `Фильтр`, выбрать цвет, применить.
- Сбросить фильтр.
- Нажать `Сортировка`, выбрать `Сначала дешевле`.
- Нажать `Сортировка`, выбрать `По названию А-Я`.
- Открыть `Поиск`, ввести `откос`.
- Открыть `Поиск`, ввести артикул, например `SLP`.
- Открыть найденную карточку.
