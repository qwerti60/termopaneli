# Каталог откосов

Документ описывает стартовый набор откосов для загрузки в БД и вывода в приложении через API.

## Назначение

Откосы используются при расчете фасада и оформлении оконных/дверных проемов. Пользователь должен иметь возможность выбрать материал, цвет, размер и получить расчет количества в смете.

## Категория API

`slope`

## Поля позиции

| Поле | Требование |
| --- | --- |
| `sku` | Уникальный артикул |
| `category` | Всегда `slope` |
| `name` | Название откоса |
| `material` | Пластик или металл |
| `color` | Цвет |
| `width_mm` | Ширина |
| `length_mm` | Длина |
| `thickness_mm` | Толщина, если применимо |
| `unit` | `шт`, `пог. м` или другая согласованная единица |
| `price` | Цена за единицу |
| `image_path` | Путь к изображению |
| `is_active` | `1` для активных позиций |

## Правила расчета

- Количество откосов рассчитывается по периметру оконных и дверных проемов.
- Для расчета нужно знать ширину откоса и длину проема.
- Количество округляется вверх до целой штуки или до упаковки, если упаковка будет добавлена в каталог.
- Если пользователь не ввел размеры окон/дверей, откосы нельзя рассчитать автоматически.
- Если выбрана позиция `Под заказ`, приложение должно показать предупреждение, что цена требует уточнения.

## Проверки перед загрузкой

- Все активные позиции должны иметь уникальный артикул.
- Все активные позиции должны иметь материал и цвет.
- Цена должна быть заполнена реальным значением перед production.
- Изображения должны быть загружены на сервер или заменены заглушкой.
- Неактивные позиции не должны отображаться в приложении.
