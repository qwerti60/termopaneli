# Каталог дополнительных элементов

Документ описывает стартовый набор дополнительных элементов для фасада. Эти позиции нужны для расчета сметы, выбора материалов и последующей загрузки в БД.

## Категории API

| Категория | Код |
| --- | --- |
| Уголки | `corner` |
| Затирка | `grout` |
| Отливы | `ebb` |
| Софиты | `soffit` |
| Подшивка софитов | `soffit_lining` |
| Фронтальные свесы | `front_overhang` |
| Элементы цоколя | `plinth` |
| Крепеж | `fastener` |
| Расходники | `consumable` |

## Правила расчета по категориям

### Уголки

- Рассчитываются по длине внешних и внутренних углов.
- Количество округляется вверх до целой штуки.
- Нужно учитывать длину одной позиции.

### Затирка

- Рассчитывается по площади фасада и норме расхода.
- Норма расхода должна храниться в БД или настройках расчета.
- Количество округляется вверх до целого мешка.

### Отливы

- Рассчитываются по ширине оконных проемов.
- Количество округляется вверх по длине одной позиции.
- Цвет желательно подбирать под цвет окна или фасада.

### Софиты и подшивка

- Рассчитываются по длине карнизных участков и ширине подшивки.
- Для перфорированных софитов нужно учитывать вентиляционные требования.

### Фронтальные свесы

- Рассчитываются по длине фронтальных участков.
- Материал и цвет должны согласовываться с выбранным фасадом.

### Элементы цоколя

- Рассчитываются по периметру цоколя.
- Стартовый профиль может быть обязательной позицией при выборе панелей.

### Крепеж и расходники

- Рассчитываются по норме на площадь или на количество панелей.
- Нормы расхода должны быть согласованы отдельно.

## Проверки перед загрузкой

- Все активные позиции имеют уникальный артикул.
- У каждой позиции заполнена категория.
- У каждой позиции задана единица измерения.
- Все цены заменены на реальные значения.
- Изображения загружены на сервер или заменены заглушками.
- Позиции с неизвестной ценой должны быть неактивны или отмечены как `цена по запросу`.
- API должен возвращать только активные позиции для пользовательского каталога.
