1. Начало работы в приложении

Приложение позволяет просматривать каталог термопанелей и сопутствующих материалов, собирать смету, сохранять её в аккаунте и отправлять как заявку в компанию.

Гость и вход

  • Без регистрации можно листать каталог и собирать смету на устройстве.
  • Сохранить смету на сервере, открыть список сохранённых смет и отправить заявку можно после входа в аккаунт (обычно по номеру телефона и коду из SMS).

Если кнопка просит войти — выполните вход с экрана профиля или там, где приложение предложит авторизацию.

2. Каталог и карточка товара

  • В каталоге выберите категорию или воспользуйтесь поиском.
  • Откройте карточку товара: описание, цена (если указана), при необходимости — размеры и подсказки.
  • Укажите количество и нажмите «Добавить в смету». При повторном добавлении того же товара количество в смете увеличится.
  • Для части материалов приложение может запросить уточнение размеров — это нужно для корректного расчёта.

Для панелей на фасад может быть доступна примерка / маска (отдельный экран) — следуйте подсказкам на экране.

3. Смета: материалы и работы

Экран «Смета» — центральное место расчёта.

Вкладка «Материалы»

  • Список добавленных позиций: можно менять количество кнопками +/− или удалить строку.
  • Для расчёта панелей по площади укажите площадь фасада в м² (если предусмотрено) и воспользуйтесь пересчётом по подсказкам на экране.
  • Запас на подрезку (%) влияет на итоговое количество панелей — значение можно изменить перед расчётом.
  • Очистить смету — удаляет все позиции с экрана (несохранённое на сервере не восстановить).

Вкладка «Работы»

  • Добавляйте типовые работы (например, по площади) или отдельные позиции из прайса.
  • При необходимости задайте скидки (по строке или на смету) — итог пересчитается.

Поделиться

Через системное меню «Поделиться» можно отправить текст сметы или PDF — удобно для согласования с семьёй или прорабом до отправки официальной заявки.

4. Сохранение сметы и заявка

  1. Убедитесь, что вы вошли в аккаунт.
  2. На экране сметы нажмите «Сохранить» — смета уйдёт на сервер и появится в разделе сохранённых.
  3. В «Сохранённые сметы» (личный кабинет) можно открыть смету, отредактировать, удалить или отправить в заявку.
  4. «В заявку» / «Отправить как заявку» — создаёт заявку для офиса. Контакты подставляются из профиля; при желании добавьте комментарий в форме отправки.

После отправки заявку обрабатывает менеджер; статус можно смотреть в приложении в разделе «Мои заявки» (после обновления данных).

5. Личный кабинет

Раздел профиля объединяет сервисные функции:

  • Профиль / мои данные — ФИО, email; телефон обычно привязан при входе и отображается для контроля.
  • Сохранённые сметы — черновики на сервере; переключение «Сметы» / «Заявки» для удобства.
  • Мои заявки — сметы, по которым уже создана заявка и назначен статус.
  • Выход — завершает сессию на устройстве и на сервере (повторный вход потребует новый код).

Пункты для сотрудников (например, вход администратора в список заявок) в меню не мешают обычному пользователю — ими пользуется только персонал с учётной записью.

6. Для менеджера: связь с веб-админкой

Эта веб-страница открыта из админ-панели рядом с каталогом и заявками. Ниже — как стыкуется работа офиса с приложением клиента.

Что делает клиент в приложении

  • Собирает смету → сохраняет (запись в БД) → при необходимости отправляет заявку.
  • Пока клиент только сохранил смету без заявки, в разделе «Заявки» веб-админки строки может не быть — заявка появляется после шага «в заявку».

Где смотреть в админке

  • Заявки и сметы — таблица входящих заявок, смена статуса, переход к просмотру сметы и PDF.
  • Сметы (все) — полный список сохранённых смет по пользователям; удаление отсюда удаляет и позиции, и связанную заявку (каскад в базе).
  • Панели / материалы / работы — содержимое каталога и прайсы, из которых клиент собирает смету.

Практические советы

  • Просите клиента указать в заявке комментарий (этаж, подъезд, сроки) — поле доступно при отправке.
  • Если клиент «застрял» на старой смете — пусть откроет сохранённую смету из ЛК или соберёт новую и снова сохранит.
  • Телефон и имя для связи берутся из профиля пользователя в приложении — при пустых данных уточните контакты у клиента.

Документ статичный: при обновлении приложения часть экранов и названий кнопок может слегка отличаться — ориентируйтесь на подписи в интерфейсе.
